# Landing pages

Repositório de landing pages criadas com o Claude Code.

As skills (taste-skill, ui-ux-pro-max e agent-skills) são instaladas automaticamente em toda sessão aberta neste repositório, pelo `.claude/settings.json`.

## Como usar

```
/landing página para uma clínica odontológica em Curitiba, foco em agendamento pelo WhatsApp
```

O fluxo completo está no `CLAUDE.md`.

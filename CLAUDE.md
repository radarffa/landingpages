# Landing pages

Este repositório guarda landing pages. Cada página fica na sua própria pasta em `pages/<nome>/`.

## Fluxo obrigatório

Ao criar ou alterar uma landing page, siga sempre estes passos:

1. **Briefing**: se faltar produto, público, objetivo (CTA) ou tom, pergunte antes de começar.
2. **Direção de arte**: use a skill `taste-skill:design-taste-frontend` para definir a direção visual.
3. **Sistema visual**: use a skill `ui-ux-pro-max:ui-ux-pro-max` para escolher estilo, paleta, fontes e as regras de UX do stack.
4. **Implementação**: use a skill `agent-skills:frontend-ui-engineering` para construir a página acessível e responsiva.
5. **Verificação**: abra a página num navegador real (desktop e celular) e confira o resultado.
6. **Revisão**: rode `/agent-skills:review` antes de entregar.

## Padrões

- Textos da página em português do Brasil, salvo pedido em contrário.
- Sem copiar marca, textos ou imagens de outras empresas.
- Imagens só de fontes livres, com os créditos registrados.
